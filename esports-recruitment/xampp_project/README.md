# คู่มือการติดตั้งระบบ Esports Recruitment ด้วย XAMPP (Localhost)

ระบบนี้คือระบบคัดเลือกตัวนักกีฬาระดับโลก ด้วยเทคโนโลยี **AR Hand Tracking** (จับการเคลื่อนไหวของนิ้วมือผ่านกล้อง Webcam เพื่อชนดวงดาวจับความเร็วในการตอบสนอง)

## โครงสร้างไฟล์ในโฟลเดอร์นี้:
1. `database.sql` - ไฟล์จำลองและโครงสร้างฐานข้อมูล MySQL
2. `db.php` - ไฟล์สำหรับเชื่อมต่อฐานข้อมูลโดยใช้ PDO
3. `index.php` - หน้าหลักแสดงข้อมูลและฟอร์ม Login ล็อกอิน
4. `register.php` - หน้าลงทะเบียนพร้อมระบบสุ่มสร้างรหัสประจำตัวนักกีฬา (Player ID)
5. `game.php` - หน้าเกม AR จับภาพมือโดยใช้ MediaPipe Hands และ HTML5 Canvas
6. `update_score.php` - หน้า API สำหรับรับคะแนนผ่าน AJAX/fetch ไปอัปเดตสถิติสูงสุด
7. `logout.php` - ระบบทำลาย Session ล็อกเอาต์อย่างปลอดภัย

---

## วิธีการติดตั้งบนคอมพิวเตอร์ของคุณ (XAMPP):

### ขั้นตอนที่ 1: คัดลอกโฟลเดอร์ระบบไปที่ htdocs
1. เปิดโปรแกรม XAMPP และดาวน์โหลดโฟลเดอร์นี้ไปเก็บไว้
2. นำโฟลเดอร์ `xampp_project` (หรือเปลี่ยนชื่อโฟลเดอร์ตามที่คุณชอบ เช่น `esports`) ไปวางในโฟลเดอร์โปรเจกต์ของ XAMPP:
   - **Windows:** `C:\xampp\htdocs\`
   - **macOS:** `/Applications/XAMPP/htdocs/`

### ขั้นตอนที่ 2: สร้างฐานข้อมูลและนำเข้าข้อมูล (MySQL)
1. เปิดโปรแกรม **XAMPP Control Panel** จากนั้นกด **Start** ที่โมดูล **Apache** และ **MySQL**
2. เปิดเว็บเบราว์เซอร์แล้วเข้าไปที่ [http://localhost/phpmyadmin](http://localhost/phpmyadmin)
3. กดที่แท็บ **"SQL"** ด้านบน
4. คัดลอกโค้ดทั้งหมดภายในไฟล์ `database.sql` ในโปรเจกต์นี้มาวางลงในช่องรันคำสั่ง SQL
5. กดปุ่ม **"Go"** ด้านล่างขวาเพื่อทำการรันคำสั่ง ระบบจะสร้างฐานข้อมูลชื่อ `esports_db` และตาราง `users` ให้ทันที

### ขั้นตอนที่ 3: เข้าใช้งานผ่านเว็บเบราว์เซอร์
1. เปิดเบราว์เซอร์ของคุณ (แนะนำเป็น Google Chrome, Microsoft Edge, หรือเบราว์เซอร์ที่รองรับกล้อง)
2. เข้าลิงก์: [http://localhost/xampp_project/index.php](http://localhost/xampp_project/index.php) (หรือเปลี่ยนชื่อพาร์ทตามโฟลเดอร์ที่คุณตั้งไว้)
3. กดสมัครสมาชิกที่ปุ่ม **"ลงทะเบียนโปรเพลเยอร์ (Register)"** ระบบจะให้ชื่อผู้ใช้และสุ่มสร้าง Player ID (เช่น NXS-58291)
4. ใช้รหัสผ่านและชื่อผู้ใช้ดังกล่าวกลับมาล็อกอินในหน้าแรกเพื่อเข้าสู่การทดสอบเกม AR Hand Tracking!

## หมายเหตุความปลอดภัยด้านการใช้กล้อง (Webcam):
- ปัจจุบันเว็บเบราว์เซอร์ทั่วไปจะล็อกสิทธิ์ไม่ให้ใช้งานกล้อง Webcam หากไม่ได้เข้าใช้ผ่าน `localhost` หรือโปรโตคอลความปลอดภัย `https://`
- ดังนั้นเมื่อคุณใช้งานบน **XAMPP (http://localhost/...)** เบราว์เซอร์จะอนุญาตให้ใช้กล้องได้อย่างปลอดภัยแน่นอน 100%!
